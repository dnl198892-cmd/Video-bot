# 🤖 Универсальный Telegram Бот

Этот бот — мой личный проект, объединяющий в себе несколько полезных функций.

## 🚀 Что умеет бот:
*   🎬 **Оживление фото:** Отправьте фотографию с описанием, и бот сгенерирует видео (используется API Magic Hour).
*   🍿 **Поиск фильмов:** Находит постер, рейтинг и описание фильма (используется API Кинопоиска).
*   🎵 **Поиск музыки:** Находит треки и присылает отрывок для прослушивания (iTunes API).
*   📺 **IPTV:** Автоматически собирает, проверяет и отдает плейлист с рабочими телеканалами.
*   🍳 **Кулинария:** Ищет рецепты по ингредиентам.
*   🌍 **Переводчик:** Переводит текст на разные языки.
*   🎮 **Игры:** Встроенные мини-игры (Змейка, Угадай число, Текстовый Марио).

## 🛠 Технологии:
*   Python 3
*   Библиотека `python-telegram-bot`
*   Нейросети (OpenRouter, Llama 3)
*   Хостинг: Render.com

## ⚙️ Установка (для разработчиков):
1. Склонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`
3. Добавьте ключи в переменные окружения (`TELEGRAM_TOKEN`, `MAGIC_HOUR_KEY` и т.д.).
4. Запустите: `python main.py`
